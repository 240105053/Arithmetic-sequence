# Arithmetic Sequence AI Tutor

## Project Overview
An interactive mathematics learning website that uses AI to
teach arithmetic sequences at three difficulty levels.

## Features
- Foundation, Standard, and Advanced levels
- AI-generated arithmetic sequence problems
- Personalized hints and step-by-step explanations
- Instant feedback on student answers
- Responsive design for phones and computers

## Technologies
- HTML, CSS, and JavaScript
- Node.js serverless API on Vercel
- OpenAI API (gpt-4o-mini)

## Run Locally
1. Install Node.js.
2. Install the Vercel CLI: npm install -g vercel
3. Install dependencies: npm install
4. Add OPENAI_API_KEY to a local .env file.
5. Run: vercel dev
6. Open the local URL shown in the terminal.

Never commit your .env file or publish your API key.

## Deployment
Import this repository into Vercel and add OPENAI_API_KEY
under Project Settings > Environment Variables.
Redeploy after saving the variable.

## Learning Objective
Help learners understand common differences, nth terms,
arithmetic series, and real-world applications.
